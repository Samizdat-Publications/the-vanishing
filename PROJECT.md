## Technical Details of Current Tracker

### Stack
- Single-file HTML (1233 lines)
- TypeUI "Levels" design system (CSS custom properties)
- Fonts: Inter + JetBrains Mono (Google Fonts)
- SVG network diagram (viewBox 0 0 1400 900)
- Vanilla JavaScript for filtering and navigation
- No build tools, no dependencies beyond CDN fonts

### Key Features
- Stats bar (dead/missing/institutions/months)
- Filter buttons (All/Dead/Missing) using data-status attributes
- Clickable chronological timeline strip
- SVG network crossover diagram with person nodes + institution nodes + connection lines
- Individual case cards with status badges
- Deep analysis threads (10 threads)
- Geographic cluster sections (CA, NM, AL)
- Institution cards grid (12 institutions)
- Counterarguments section
- Open questions section
- Source URLs in footer

### CSS Architecture
- Custom properties for all colors, spacing, shadows, radii
- Card-based layout with hover states
- Responsive grid (3-col -> 2-col -> 1-col)
- Status-based coloring (red=dead, amber=missing, violet=institution)
- Monospace date columns in timeline tables

### JavaScript
- `filterCards(status)`: shows/hides case cards by data-status
- `scrollToCard(id)`: smooth scrolls to a case card by ID
