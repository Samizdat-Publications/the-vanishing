DOT LEADER ROWS · THE DENSITY WORKHORSE
{{ l.row }}
A key, a dot fill, a value, in one white-space:pre element at a fixed character width. Two aligned columns with no table and no alignment CSS. Absent values print as absent, never as blank or zero. Widths in use: 22 rail, 37 connections, 38 record, 40 case rows, 46 geography, 52 left-behind — each set to the widest leader that fits its column at 10px, since an over-wide leader clips rather than wraps.

04 · EDGES · CIRCUIT ROUTING, STRENGTH, FLOW
Right-angled traces, one per pair, one mitred corner. Weight is the number of independent connection types tying that pair together, so a thick bright trace means several categories agree. One shared employer is weak evidence; employer plus geography plus domain plus timing is where a reader should look first. Computed, not authored.
WEIGHTLABELIDLE HEXWIDTHEXTRA
{{ s.weight }} {{ s.label }} {{ s.hex }} {{ s.width }} {{ s.extra }}
Particles walk each trace by arc length at 0.000115 px/ms, one per link type, phase-offset per pair so they never march in lockstep. Direction carries meaning: between two people it runs earlier date to later date, so the flow reads as the sequence of events; elsewhere it runs from the person outward. At rest only corroborated pairs animate, so the idle map reads as signal rather than noise. A selection animates everything inside it.
