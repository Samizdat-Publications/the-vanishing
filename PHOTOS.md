### loureiro -- Nuno Loureiro -- CLEARS (free licence, with two caveats)

| Field | Value |
|---|---|
| Image found | Yes. "Nuno teaching Introduction to Plasma Physics I course at MIT", photographed 16 November 2023. |
| Direct image URL | `https://upload.wikimedia.org/wikipedia/commons/9/96/Nuno_Loureiro_teaching.jpg` (4624 x 3472) |
| Page URL | https://commons.wikimedia.org/wiki/File:Nuno_Loureiro_teaching.jpg |
| Licence | Creative Commons Attribution-ShareAlike 4.0 International. https://creativecommons.org/licenses/by-sa/4.0 . Uploaded 16 December 2025 by Commons user Apandada1, tagged "own work". Attribution required flag is set true. |
| Attribution string | `Photo: Apandada1, CC BY-SA 4.0, via Wikimedia Commons` |

**Caveat 1, share-alike.** CC BY-SA 4.0 permits commercial use and derivatives, which CC BY-NC-ND does not, so this is the strongest licence on the entire list. But ShareAlike attaches to adaptations. Standard practice is that using an unmodified still inside a film is not an adaptation of the photo, so the film itself is not forced open. If you plan to crop, colour grade, or apply motion treatment, get that confirmed by counsel before locking picture.

**Caveat 2, provenance.** "Own work" on Commons is a self-declaration by an anonymous uploader. It is not independently verified. Given this is a homicide case with an active family, I would spot-check the uploader before broadcast.

**Rejected alternative, and this matters.** The MIT News obituary portrait at `https://news.mit.edu/sites/default/files/download/202512/MIT-Nuno-Loureiro-01a-PRESS.jpg` (page: https://news.mit.edu/2025/nuno-loureiro-professor-director-plasma-science-and-fusion-center-dies-1216) carries an explicit MIT terms of use notice: released "under a Creative Commons Attribution Non-Commercial No Derivatives license", credit "Photo: Jake Belcher". **Non-Commercial plus No-Derivatives is incompatible with a commercially distributed documentary and forbids any alteration beyond cropping.** Do not use the MIT News file. Use the Commons file.

| Direct image URL (portrait) | `https://www.ipac.caltech.edu/system/news_items/images/408/original/grillmair-bg.png` |

| Page URL | https://www.ipac.caltech.edu/news/ipac-mourns-passing-of-carl-grillmair |
| Terms | https://www.ipac.caltech.edu/page/image-use-policy |

**Why this is flagged ASK and not CLEARS.** Per your instruction, Caltech IPAC is marked ASK by default. But the finding runs against the assumption and you should see it: IPAC's Image Use Policy is not a reservation of rights, it is a **blanket permission grant**. Verbatim: "Unless otherwise noted, images and video on the IPAC public web sites (public sites ending with a ipac.caltech.edu address) may be used for any purpose without prior permission." The policy also states that third-party ownership "is noted in the caption material and/or image credit with each image". Neither Grillmair image carries any credit line or third-party notice, so on the policy's own terms both fall inside the blanket grant.

Two things still need a human decision:
1. The policy's "identifiable person" clause warns that commercial use of an identifiable person's likeness may implicate right of privacy or publicity. Documentary use is editorial, not commercial in the merchandising sense, but this is a judgement call.
2. Wikipedia's editors independently assessed the same portrait as **non-free** and hosted it under a fair use rationale (File:Carl Grillmair.jpg, credited to the caltech.edu version of the obituary). That is a competing read worth knowing about. Note the distinction: the caltech.edu main-site copy is governed by Caltech's site terms, the ipac.caltech.edu copy is governed by the IPAC blanket grant above. If you proceed, take the IPAC-hosted URL, not the caltech.edu one.

| Attribution string if approved | `Courtesy NASA/JPL-Caltech` (the exact credit line the IPAC policy specifies) |

**Standing legal points applied throughout**

1. 17 U.S.C. 105 covers works of **US federal government employees**. It does not cover state universities (UAH, University of Arizona) or FFRDC contractor staff (Caltech/JPL, Caltech/IPAC, Triad/LANL, Honeywell/KCNSC).
2. A blanket permission grant is not the same thing as public domain. JPL and IPAC both grant broad permission but retain the framing of a licence. Every attribution string below reflects the credit line the policy itself specifies.
3. No image in this report was described as public domain without a specific policy page quoted for it. The only true public domain call on the list is McCasland's af.mil portrait.
